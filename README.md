## 🌟 Overview

Welcome to my personal portfolio repository! 🚀

This application is built from the ground up to showcase **who I am as a developer, researcher, and engineer**. Blending a minimal **white + rich royal dark pink** aesthetic with interactive **WebGL 3D graphics, dynamic lighting, and scroll-choreographed camera movement**, this portfolio delivers a futuristic yet ultra-refined user experience.

---

## ✨ Key Features & Visual Highlights

- 💎 **Interactive 3D Hero Gem**: A custom morphing gemstone with transmission shaders and orbiting quantum satellites that react to cursor position and gyroscopic device orientation in real time.
- 🎥 **Scroll-Synchronized Camera Rig**: Smooth camera damping interpolates `(x, y, z)` perspective and viewport target coordinates across each section as you scroll.
- 🎨 **Rich Royal Dark Pink Aesthetic**: Refined styling using `#BE185D`, `#DB2777`, `#9D174D`, frosted glass panels (`backdrop-blur-2xl`), and holographic borders.
- ⚡ **Spotlight Command Palette (`⌘K` / `Ctrl+K`)**: Rapid keyboard-driven navigation, skill searches, and instant contact copy actions.
- 🔍 **Interactive Project Inspector Modals**: Comprehensive case study deep-dives detailing system architectures, performance metrics, and celebratory confetti.
- 🔊 **Synthesized Web Audio Feedback**: Native Web Audio API sound effects for clicks, hovers, and successful transmissions (toggleable in navigation).
- 📊 **GitHub Activity Heatmap**: Interactive commit density visualizer and live dual-language code viewer (TypeScript & Python).
- 📱 **Fully Responsive & Performance-Tuned**: Optimized 60 FPS rendering on both mobile and desktop viewports.

## 💻 Getting Started (Run Locally)

### 1. Clone the repository
```bash
git clone https://github.com/Afsu03/My_Portfolio.git
cd My_Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

### 4. Build for production
```bash
npm run build
```

## 🌐 Deployment (GitHub Pages)

This repository includes an automated GitHub Actions deployment workflow at `.github/workflows/deploy.yml`.

To deploy:
1. Go to **Settings** > **Pages** in this repository.
2. Select **GitHub Actions** as the deployment source.
3. Every push to the `main` branch will automatically build and publish the live site at:
   **[https://afsu03.github.io/My_Portfolio/](https://afsu03.github.io/My_Portfolio/)**
