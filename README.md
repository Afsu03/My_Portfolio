## Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/Afsu03/My_Portfolio.git

# 2. Navigate to project directory
cd My_Portfolio

# 3. Install dependencies
npm install

# 4. Start the local development server
npm run dev

# 5. Build for production
npm run build
```
